# Impacto Fitness Bootstrap

Website institucional responsivo para academia desenvolvido com HTML5, CSS3 e Bootstrap 5.

## Sobre o Projeto

O projeto foi desenvolvido como atividade da disciplina de Full Stack, com o objetivo de criar uma landing page para uma academia utilizando Bootstrap como biblioteca principal de componentes.

## Funcionalidades

- Navbar responsiva
- Hero Header
- Carousel de imagens
- Seção de modalidades
- Layout responsivo
- Identidade visual personalizada (preto, vermelho e branco)

## Tecnologias Utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Modalidades

- Karate
- Musculação
- Luta Livre
- Zumba
